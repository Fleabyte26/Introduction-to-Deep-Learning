Image augmentation: one picture becomes many

A network learns from the pictures you give it, and it learns everything about them, including things you did not mean to teach. If every boot in the training set points left, “points left” becomes part of what a boot is. Image augmentation is the fix: change each training picture a little, at random, every time the network sees it. The label stays the same; the accidents do not. Try each change on one picture, then see what it did to a real network.

One image, a new version every epoch

Augmentation does not make a bigger dataset on disk. The changes are drawn fresh each time a picture is loaded, so the network sees the same boot in every epoch and never the same pixels twice. Here are eight draws from the book’s recipe: a random left-right flip, a random crop of 10% to 100% of the area, and random brightness and hue.

The one rule: the label must survive

An augmentation is only allowed if the answer is still the same afterwards. That depends on the subject, not on the operation. Pick a subject and look at the four flips.

What it does to a real network

A small convolutional network, trained on 1,000 pictures from Fashion-MNIST (100 per class), four times. The only thing that changes is the augmentation. Then each network is tested three ways: on normal test pictures, on the same pictures mirrored, and on the same pictures moved two pixels right and two pixels down. In the dataset, every shoe points left and every item sits in the centre.

Two details the code depends on

Training only. The random changes are for learning. At test time you want one definite answer per picture, so the test pipeline has no randomness in it. In the book’s CIFAR-10 example the training transform is a random left-right flip, and the test transform does nothing but convert the image to numbers.

Free, and applied on the fly. No new photos are taken and nothing extra is stored. The cost is a little computation each time a picture is loaded. The book says augmentation was probably indispensable to the success of AlexNet, the 2012 network that started the modern era of computer vision.

The book’s numbers. Random crop: 10% to 100% of the area, width-to-height between 1:2 and 2:1, then resized back to a fixed size. Colour: brightness, contrast, saturation and hue each changed at random, by up to 50% in the book’s example. In PyTorch these are RandomHorizontalFlip, RandomResizedCrop and ColorJitter, chained with Compose.
