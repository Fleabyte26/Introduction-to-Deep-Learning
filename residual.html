The arrow that made networks deep

In 2015 a 56-layer network scored worse than a 20-layer one on the training set. Not overfitting, the opposite: the deeper network could not even fit the data it was shown. A deeper model contains every shallower model as a special case, so this should have been impossible. The fix was one arrow, and it is why networks went from twenty layers to a hundred and fifty.

One block, with and without the arrow

Why the arrow makes depth safe

Ask either block to leave its input alone, which is what the extra layers of a too-deep network ought to do. The plain block has to learn f(x) = x with its own weights: every filter, exactly right, to copy the input through untouched. That is a hard target to hit by gradient descent, and a block that misses it damages the signal.

The residual block only has to learn f(x) = 0, because the arrow already carries x forward. Pushing weights toward zero is the easiest thing gradient descent does. So the extra blocks of a deep residual network can sit out harmlessly until they find something useful to add, and adding depth can no longer make training worse.

That is the argument in the book, and it is about what the network can represent. There is a second, mechanical reason, and you can watch it below.

Backpropagation multiplies, block by block. If each block scales the gradient by 0.8, then after thirty blocks what arrives is 0.8 multiplied by itself thirty times. The skip connections add a second route in which the gradient is multiplied by 1 every time, so something always arrives, however deep the network is. This is a deliberately simple model of a real backward pass, where the factor differs per block and the two routes are summed, not separate. It gets the shape of the problem right, not the exact numbers.

The practical details

When the shapes do not match. The arrow adds x to the block's output, so the two have to be the same shape. When a block changes the channel count or uses stride 2, the skip gets a 1×1 convolution to match it, which is the cheap channel-changing trick from the channels page. Keras calls this the projection shortcut.

Where the addition goes. The arrow joins after the block's last batch normalization and before the final activation, so the sum passes through one ReLU on the way out. Plenty of diagrams get this wrong.

What it bought. ResNet-152 was eight times deeper than VGG-19 and still had fewer parameters, because it leaned on depth and 1×1 bottlenecks rather than wide fully connected layers. The same arrow is in nearly every architecture since, transformers included.
