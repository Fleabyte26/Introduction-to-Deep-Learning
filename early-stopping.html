Early stopping: the pattern first, the noise later

A network big enough to memorize anything is trained on points where some labels are wrong. It learns the real pattern first and only later bends itself around the wrong labels. Early stopping keeps the model from the moment validation loss was lowest. Press Play.

How early stopping decides: every 10 steps it checks the validation loss. If the loss has not improved for the number of checks set by Patience, training stops and the best model seen so far is kept. Here training carries on past that point so you can see what stopping saved you from.

This is the argument of Section 5.5 of Dive into Deep Learning: with label noise, networks tend to fit the cleanly labeled data first and only afterwards the mislabeled data, so stopping early acts as a regularizer. Set Wrong labels to 0% and the book's other point shows up: with clean, separable data, early stopping saves time but changes little.

What runs here: a real network trained live in your browser, with 2 inputs, 200 hidden ReLU units and 1 output, on 80 training points, using the Adam optimizer. Validation loss is measured on 300 other points whose labels are noisy at the same rate. "Accuracy on new points" compares against the true classes.
