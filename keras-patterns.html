Keras in five moves, and nine ways to break it

Every Keras program has the same five moves: build, compile, fit, evaluate, predict. Once you see the pattern, the code stops looking like a wall. Then comes the part nobody tells you: almost every error a beginner hits is a comma, a bracket or a capital letter. The nine bugs at the bottom are real. I made every one of them in a single afternoon, typing code by hand instead of pasting it. Each one shows the exact message Python gave back.

Three habits that prevent most of them

Copy, do not retypeEight of the nine bugs above came from typing code by hand. A comma, a bracket, a capital letter: the eye skips them and Python does not. If code is given to you, paste it.
Read the last line firstA Python error is long and red, and the useful part is at the bottom: the type of error and one sentence. Then look at the line the arrow points to, and the line above it.
Restart and run allA notebook remembers everything you ran, in the order you ran it. Before you trust a result, restart the kernel and run every cell from the top. It is the only way to know the code on the page produced the numbers on the page.

The five-move pattern is standard Keras, the library used in most introductory deep learning courses. It goes with the convolutional network chapters of Dive into Deep Learning. The model on this page is a small example made for it. Every error message is the real output of Python 3.13, Keras 3 and scikit-learn for that exact mistake.
