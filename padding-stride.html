Padding and stride you can drag

A convolution slides a small window over an image and writes one number per position. How many positions there are, and therefore how big the output is, depends on three settings. The formula for it is the part of Chapter 7 that most people have to look up every time. Drag the four sliders and watch the output size follow.

The three jobs these settings do

Padding keeps the size up. With no padding, every convolution shrinks the image by k−1 pixels. Stack twenty 3×3 layers and you have lost 40 pixels, which is most of a small image. Set padding to (k−1)/2 and the output is the same size as the input, which is why 3×3 with padding 1 is the most common pair in modern networks. Try the "Same size" preset.

Stride brings the size down, on purpose. A stride of 2 halves the height and width, and cuts the work for every layer that follows to a quarter. This is how a network goes from a 224×224 image to a 7×7 feature map without a thousand layers. Try "Halve it".

The corner case worth knowing. When the stride does not divide the available space evenly, the last rows and columns are simply never visited. If the leftover is padding, nothing real is lost. If it reaches into the image, those pixels are discarded and nothing warns you. The red cells mark that second case: try the "Cells get dropped" preset.

Reading the formula

The window starts at the left edge of the padded input and moves by s each time, so the number of positions is how many steps of size s fit into the room the window has, plus one for the starting position itself. That is the whole derivation:

room = n + 2p − k  →  steps = ⌊room / s⌋  →  output = steps + 1

The floor is what throws away the leftover. Height and width are computed separately and do not have to match, and the same formula covers pooling layers, which are convolutions without weights.

From sections 7.1 to 7.3 of Dive into Deep Learning. The book writes padding as the total across both sides; this page uses padding per side, which is what Keras and PyTorch take as an argument.
