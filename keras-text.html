Keras for text: from words to a model, and eight ways to break it

A network cannot read. Before any model sees a sentence, three lines of Python turn the words into numbers and make every sentence the same length. After that, a recurrent network, an LSTM, a two-direction LSTM and an attention model are the same five lines with one of them changed. This page walks through that code with a small example made for it, and ends with eight real mistakes from one afternoon of typing it by hand. Two of them give no error at all.

Two ways to write the same model

Keras lets you stack layers, or wire them. Stacking is shorter. Wiring is needed as soon as a layer takes more than one input, and attention does: the same word vectors go in twice, once as the questions and once as the things being looked at.

Three habits for this kind of code

Read the summary before you trainThe parameter count is a fingerprint. With 16 units on 16-number vectors, a plain recurrent layer is 528, an LSTM is 2,112 and a two-direction LSTM is 4,224. If the number is not the one you expect, the model is not the one you meant, and you find out in a second instead of after five passes of training.
When you copy a cell, change the important line firstA copied cell needs its names changed in six places and its one meaningful line changed once. The names are easy to see. The meaningful line looks right because it was right, for the previous model.
Python never checks what is inside quotesA misspelled layer name stops the program. A misspelled dictionary key or column name does not. It becomes a new, valid, wrong name, and the error appears later and somewhere else. Copy keys from the instructions; do not type them.
