Attention: do not remember, look back

A recurrent network carries everything it knows forward in one small memory, and the plain kind loses it. An LSTM protects that memory with gates. Attention asks a different question: why carry anything? The whole sentence is still there. When the network needs the animal, it can go back and look at it directly, in one step, no matter how far back it is. The network below was trained on the same sentences as the other two. Queries, keys and values, by hand

Attention is a lookup, but a soft one. Each stored item has a key, which says what it is about, and a value, which is what it holds. The query is the question. The query is compared with every key, the scores are turned into shares that add up to 100%, and the answer is the values mixed in those shares. Turn the query and change the sharpness.

The rest of the chapter, in four sentences

Scoring. The score between a query and a key here is a dot product, divided by the square root of the vector size so that long vectors do not make the shares too sharp. The book also covers additive scoring, where a small network compares the two instead. Both end in the same softmax.

Where it started. Attention was first added to translation, in the Bahdanau model: an LSTM-style encoder reads the source sentence, and at every output word the decoder looks back over all of the source words instead of relying on one final memory.

Several heads. One head can look for one kind of thing. Multi-head attention runs several in parallel, each with its own queries, keys and values, and joins the results. The network at the top has two heads, and you can see that they learned different jobs.

What comes next. Remove the recurrent network entirely, keep only attention, stack it in layers, and you have the transformer, the design behind today’s large language models.
